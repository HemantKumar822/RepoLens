# Design history

This folder keeps the product and implementation plans that shaped RepoLens. They are point-in-time design notes, not a current roadmap or a checklist for the shipped app. Some early plans describe layouts and technical choices that changed as the project evolved.

For the current experience and setup, start with the [project README](../../README.md) and follow the source code. The guides below are useful for understanding how the direction developed:

- [Interactive codebase explorer](interactive-codebase-explorer.md) — the original map-and-guide concept.
- [Full-screen codeworld](expedition-ui-redesign.md) — the immersive island, exploration flow, and spirit roles.
- [City world generation](repo-city-world-generation.md) — the structured street grid and repository-driven city.
- [Living codeworld polish](living-codeworld-polish.md) — landmarks, camera focus, and the next learning-trail ideas.
